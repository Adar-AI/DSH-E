## 五、已知限制（非缺陷，均为设计取舍或硬件约束）

1. **首次提问较慢**：本地模型冷启动 + 加载 2.1GB 精排模型，实测首轮 35~80s，之后每轮 5~10s。
2. **图片问答约 35~47s**：6GB 显存装不下文本与视觉两个模型，中间需要模型换页。
3. **联网兜底经常"什么都不用"**：实测按本公司型号联网会召回 Canon/HP 的同名错误码（含义相反），
   因此联网结果必须包含可判别实体（型号/品牌），不合格一律丢弃——对内部专用产品，返回 0 条是正确行为。
4. **改了后端代码必须重启服务**：静态页面是每次从磁盘读的，容易出现"新按钮出现了但接口还是旧的"
   （本次试点就踩到：`结束会话` 报 404 → 提醒栏没清）。前端已加自愈（失败也刷新提醒栏）与
   手动「✕ 移出提醒」兜底。
5. **Mock 模式**（`LLM_MODE=mock`）不调用任何模型，仅用于离线验证流程与演示。
