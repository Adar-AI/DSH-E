# 云打 L3250 · 常见故障排查表

## 屏幕报错码对照

| 报错码 | 含义 | 处理步骤 |
|---|---|---|
| E05 | 硒鼓未识别 | 打开前盖重新安装硒鼓；用干燥无绒布擦拭硒鼓芯片触点；更换新硒鼓后复位计数器。若仍报错，判定为硒鼓芯片损坏，保修期内可免费更换 |
| E06 | 硒鼓寿命到期 | 更换新硒鼓 CT-L3250，更换后在「维护」菜单执行硒鼓复位 |
| E07 | 卡纸 | 打开前盖与后盖，沿走纸方向缓慢抽出纸张，检查是否有纸屑残留；确认纸张平整、未受潮、未超过纸盒刻度线 |
| ER12 | 加热组件温度异常 | 关机断电静置 10 分钟后重启；若反复出现，属于硬件故障，需返厂维修 |
| U4 | 网络连接失败 | 确认路由器已开启 2.4G 频段；重新输入 Wi-Fi 密码；将打印机靠近路由器后重试 |

## 打印空白页

1. 确认硒鼓封条是否已完全撕除。
2. 取出硒鼓左右轻摇 5 至 6 次，使碳粉分布均匀。
3. 检查是否使用了非原装耗材，非原装硒鼓容易出现浓度不足或空白。
4. 若更换新硒鼓后仍空白，联系售后检修激光组件。

## 打印有纵向黑线或底灰

1. 打印一张测试页，观察黑线位置是否固定。
2. 用干燥无绒布清洁硒鼓表面，禁止用手直接触摸绿色感光鼓。
3. 若清洁无效，说明感光鼓已磨损，需要更换硒鼓。
4. 底灰通常与碳粉受潮有关，建议更换干燥环境保存的原装硒鼓。

## 无线连接失败

1. 确认打印机与本机在同一网络，且路由器开启了 2.4G 频段（本机型不支持 5G 频段）。
2. 在打印机「网络设置」中重新搜索并输入 Wi-Fi 密码，注意区分大小写。
3. 重启路由器与打印机，等待 1 分钟后重试。
4. 若仍失败，可用 USB 线连接后通过驱动自带的网络配置工具设置。

## 频繁卡纸

1. 检查纸张是否受潮、卷边或有褶皱，建议更换新开的 A4 纸。
2. 确认纸盒两侧限位卡扣贴合纸边，纸张数量不超过最大刻度线。
3. 清洁进纸轮与分离垫（可用微湿无绒布擦拭后晾干）。
4. 若进纸轮明显磨损发亮，需更换进纸轮组件。
